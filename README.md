# Machine Learning Projects

## 📚 Описание
Учебные проекты по машинному обучению, выполненные в рамках курсов ВШЭ.

## 🛠 Используемые технологии
- Python 3.x
- pandas, numpy
- scikit-learn
- matplotlib, seaborn

- `titanic/` — анализ данных Titanic (классификация)
- `house_prices/` — предсказание цен на жилье (регрессия)
- `classification/` — задачи классификации
